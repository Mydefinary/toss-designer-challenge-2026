# MEETSYNC

**6명이 다음 주까지 1시간 회의를 잡는 경험을 설계한 인터랙티브 프로토타입.** 빈 시간을 찾는 도구가 아니라, 6명의 제약을 **투명하게 드러내 자발적 양보를 만들고**(투명성 보드 + 슬롯 드릴다운), **1~5순위 백업**으로 확정해 갑작스러운 불참(이슈)에도 흔들리지 않게 의사결정하도록 돕습니다.

> 토스 프로덕트 디자이너 챌린지 2026 제출물. 제출 답변은 [`SUBMISSION.md`](./SUBMISSION.md) 참고.

## 기술 스택

- **React + Vite + TypeScript** — 빠른 프로토타이핑, GitHub Pages 배포 용이
- **Zustand** — 백엔드 없는 클라이언트 상태 관리
- **react-router-dom (HashRouter)** — 정적 호스팅에서도 동작하는 해시 기반 라우팅
- **CSS Modules + 디자인 토큰** — 토스풍 디자인 토큰(토스 블루 #0064FF 등) 관리
- **Vitest** — 추천 알고리즘(순수 함수) 단위 테스트

## 로컬 실행

```bash
npm i          # 의존성 설치
npm run dev    # 개발 서버 (http://localhost:5173)
npm run build  # 타입체크(tsc --noEmit) + 프로덕션 빌드 → dist/
npm test       # Vitest 단위 테스트 (또는 npm run typecheck)
```

## 5개 화면 흐름

```
회의 생성 → 제약 입력 → 추천 결과 → 확정·공유 → 운영(이슈 대응)
```

1. **회의 생성** — 제목, 1시간 고정, 기간 범위, 온라인/오프라인(장소), 참석자 6명(필수/선택 토글).
2. **제약 입력** — 참석자별 시간대 칩으로 불가/회피/가능 입력. 불가 사유 태그(외근·휴가·퇴근후·미출근·회의) 선택 또는 직접 입력(기타).
3. **추천 결과 (핵심 화면)** — (a) **투명성 보드**(6명 × 시간대 히트맵), (b) **1~5순위 후보 카드**(만족 인원·양보 주체·장소 뱃지), (c) **슬롯 드릴다운**(이 시간이 왜 부적합한지), (d) **제약 완화 제안**(후보가 희소·전무할 때).
4. **확정·공유** — 순위 리스트 확정, 요약 카드 공유(상태를 URL 쿼리로 인코딩한 링크 + 요약 PNG 다운로드).
5. **운영(이슈 대응)** — 확정된 회의 보드. "참석자 이슈 발생 → 다음 순위로 이동" 1클릭, 변경 이력·재공유.

## 데모 시나리오 5종

상단 **시나리오 셀렉터**로 즉시 전환합니다. 각 시나리오는 서로 다른 엣지케이스를 자극하도록 설계되어, 데모를 열자마자 다양한 충돌을 검증할 수 있습니다(기본값: 시나리오 1).

| # | 이름 | 검증 목적 |
|---|------|-----------|
| 1 | **전형적 충돌** | 모든 변수(필수/선택·3단계 상태·오프라인 장소)가 한 번에 작동하는 표준 케이스 |
| 2 | **완벽한 시간 없음** | 모든 슬롯에 최소 1명의 회피/불가 → "양보 없이는 불가능"을 투명성 보드가 증명 |
| 3 | **필수자 충돌 (후보 희소)** | 필수자 불가가 어긋나 후보가 1~2개로 희소 → 제약 완화 제안으로 전환 |
| 4 | **장소 병목** | 시간은 OK인데 회의실이 부족해 장소가 결정 요인이 되는 케이스 |
| 5 | **이슈 대응 (다음 순위)** | 확정 후 1순위가 무너졌을 때 다음 순위 이동이 매끄럽게 동작 |

## 배포

GitHub Pages + GitHub Actions로 자동 배포합니다. `main` 브랜치에 push하면 [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml)이 build 후 Pages에 게시합니다.

> **주의 — base 경로:** HashRouter라 서브경로 라우팅 자체는 동작하지만, **프로젝트 페이지**(`https://<user>.github.io/<REPO>/`)로 배포하면 에셋 경로 때문에 `vite.config.ts`의 `base`를 `'/<REPO>/'`로 설정해야 합니다(현재 주석 처리됨). **루트/사용자 페이지**(`<user>.github.io`)로 배포하면 불필요합니다.
